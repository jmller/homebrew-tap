# jmller Homebrew tap

Install [Dropin](https://github.com/jmller/dropin):

```sh
brew install jmller/tap/dropin
```

The formula downloads the immutable, checksummed artifact from the corresponding
GitHub release. Dropin is source-available under the terms in its
[`LICENSE`](https://github.com/jmller/dropin/blob/main/LICENSE); it is not OSI open
source.
